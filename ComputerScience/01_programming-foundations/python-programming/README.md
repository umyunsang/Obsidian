> [!abstract] 이 과목 자료의 성격
> 원본은 네 편, 모두 합쳐 27쪽뿐이다. 해설도 정답 코드도 없다. 있는 것은 **문제 설명 · 제한 조건 · 입출력 예** 세 칸이 스물한 번 반복되고, 마지막에 시험지 한 장이 붙는 구조다.
>
> 그런데 그 마지막 한 장에서 성격이 바뀐다. 스물한 문제는 예외 없이 `solution` 함수가 값을 `return`하고 입출력 예 표가 정답을 못 박는데, 중간고사 여덟 문항은 전부 `input`·`print`·`random`이다. **난수가 들어오는 순간 입출력 예라는 채점 장치가 무너지고**, 그 빈자리를 순서도가 메운다. 네 편의 정리문서는 이 전환을 축으로 묶었다.
