> [!abstract] 이 과목 자료의 성격
> 이 과목의 원본 PDF 4편에는 **해설도, 코드도, 정답도 없다.** 문제 설명과 제한 조건과 입출력 예가 스무 번 반복되고, 마지막 두 자료는 격자 그림과 순서도 그림만 남긴다.
