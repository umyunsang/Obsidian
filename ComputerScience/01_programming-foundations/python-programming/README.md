> [!abstract] 이 과목 자료의 성격
> 이 과목의 원본은 네 편, 모두 합쳐 **27쪽**이다. 다른 과목 자료와 결정적으로 다른 점이 하나 있다 — **풀이가 한 줄도 없다.** 문법 설명도, 예제 코드도, 해설도 없다. 있는 것은 문제 설명과 제한 조건, 그리고 입출력 예뿐이다.
>
> 그래서 이 자료들에서 읽어낼 것은 "어떻게 푸는가"가 아니다. **명세가 어디까지 정해져 있고 어디서부터 비어 있는가**다. 입출력 예의 한 행이 곧 판정 기준이 되고, 제한 조건의 한 줄이 풀이를 허가하거나 금지한다. 네 편 모두 그 지점을 척추로 삼았다.

## 원본에서 확인한 오류·불일치

- `문제풀이_1_10` 5쪽 — 콜라츠 문제의 제한 조건은 "1 이상 10000 이하"인데 입출력 예 세 번째 행의 입력은 **626331**이다. 제한 조건대로라면 `-1`을 반환하는 경우가 존재하지 않는다(1~10000에서 가장 오래 걸리는 6171이 261번)
- 같은 자료 4쪽 — `x = 4, n = 2 → [-4, -8]`. 답이 음수 리스트이려면 입력이 `-4`여야 한다. 이 문제에서 유일하게 음수를 다루는 행이었다
- 같은 자료 2·4·5쪽 — 입출력 예의 열 머리글이 `arr`인데 매개변수는 정수 `x`다. 표 틀을 배열 문제에서 복사해 온 흔적
- 같은 자료 1·9쪽 — 반환값을 `true`/`false`로, `signs`를 `[true,false,true]`로 적었다. 2쪽은 `True`/`False`로 올바르다
- `23-2 중간고사` 5번 — "1부터 99까지 **2자리**의 정수"인데 1~9는 두 자리가 아니다. 판정이 자릿수 위치로 이루어지므로 한 자리 입력의 처리가 정해지지 않는다
- 같은 시험지 6번 — "합**게**가 4입니다" 오타. 규칙 두 개가 겹치는 세 경우(마지막 굴림이 1 또는 6일 때, `6` 다음이 `1`일 때, `1` 다음이 `6`일 때)가 정의되지 않았다
- 같은 시험지 8번 순서도 — 범위 1~1000에 시행 상한 9회. 이분 탐색으로도 $2^9-1=511 < 1000$이라 항상 맞힐 수 없다
- 같은 시험지 4번 — 급수의 종료 조건이 없고, 여덟 문항 중 유일하게 실행 예 상자가 붙지 않았다

`문제풀이_11_20`과 `과제 02`에서는 값이 어긋나는 곳을 찾지 못했다. 두 자료의 예시(입출력 20행, 격자 7판)를 전부 파이썬으로 다시 계산해 원본과 대조했다.
