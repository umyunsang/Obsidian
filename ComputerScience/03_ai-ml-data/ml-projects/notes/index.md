# Index

## lecture

* [01. K-최근접 이웃(K-NN) 분류와 데이터 전처리 - 거리 척도(유클리드·맨해튼), 표준점수(Z-score)와 스케일링](./01.%20K-%E1%84%8E%E1%85%AC%E1%84%80%E1%85%B3%E1%86%AB%E1%84%8C%E1%85%A5%E1%86%B8%20%E1%84%8B%E1%85%B5%E1%84%8B%E1%85%AE%E1%86%BA%28K-NN%29%20%E1%84%87%E1%85%AE%E1%86%AB%E1%84%85%E1%85%B2%E1%84%8B%E1%85%AA%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%20%E1%84%8C%E1%85%A5%E1%86%AB%E1%84%8E%E1%85%A5%E1%84%85%E1%85%B5%20-%20%E1%84%80%E1%85%A5%E1%84%85%E1%85%B5%20%E1%84%8E%E1%85%A5%E1%86%A8%E1%84%83%E1%85%A9%28%E1%84%8B%E1%85%B2%E1%84%8F%E1%85%B3%E1%86%AF%E1%84%85%E1%85%B5%E1%84%83%E1%85%B3%C2%B7%E1%84%86%E1%85%A2%E1%86%AB%E1%84%92%E1%85%A2%E1%84%90%E1%85%B3%E1%86%AB%29%2C%20%E1%84%91%E1%85%AD%E1%84%8C%E1%85%AE%E1%86%AB%E1%84%8C%E1%85%A5%E1%86%B7%E1%84%89%E1%85%AE%28Z-score%29%E1%84%8B%E1%85%AA%20%E1%84%89.md) - 게으른 학습(Lazy Learning) 기반의 비모수 분류 모델 K-최근접 이웃(K-NN), 거리 측정 척도(L2 유클리드 vs L1 맨해튼 거리), 특성 간 단위/스케일 차이로 인한 거리 왜곡 현상, 표준점수(Z-score: z = (x - mu) / sigma) 및 Min-Max 정규화의 수학적 원리, 그리고 이웃 수 K와 결정 경계(Decision Boundary)의 편향-분산 트레이드오프를 인터랙티브 Z-score 정규화 계산기로 학습한다.
* [02. 회귀 모델링과 다항 회귀 - K-NN 회귀, 결정계수(R²), 다항 특성 공학(Polynomial Features)과 잔차 분석](./02.%20%ED%9A%8C%EA%B7%80%20%EB%AA%A8%EB%8D%B8%EB%A7%81%EA%B3%BC%20%EB%8B%A4%ED%95%AD%20%ED%9A%8C%EA%B7%80%20-%20K-NN%20%ED%9A%8C%EA%B7%80%2C%20%EA%B2%B0%EC%A0%95%EA%B3%84%EC%88%98%28R%C2%B2%29%2C%20%EB%8B%A4%ED%95%AD%20%ED%8A%B9%EC%84%B1%20%EA%B3%B5%ED%95%99%28Polynomial%20Features%29%EA%B3%BC%20%EC%9E%94%EC%B0%A8%20%EB%B6%84%EC%84%9D.md) - 연속형 수치값을 예측하는 회귀(Regression)의 기본 원리, 이웃들의 수치 평균을 취하는 K-NN 회귀의 한계(훈련 세트 범위를 벗어나는 외삽 Extrapolation 불가), 선형 회귀(Linear Regression: y = ax + b), 2차 이상의 곡선 관계를 포착하는 다항 회귀(Polynomial Regression: y = ax² + bx + c), 그리고 모델의 설명력을 평가하는 결정계수(R²: R² = 1 - SS_res / SS_tot)를 인터랙티브 R² 결정계수 계산기로 학습한다.
* [03. 다중 선형 회귀와 가중치 규제 - 최소제곱 정규방정식, 릿지(Ridge L2) 및 라쏘(Lasso L1) 규제 계수 하이퍼파라미터 튜닝](./03.%20%E1%84%83%E1%85%A1%E1%84%8C%E1%85%AE%E1%86%BC%20%E1%84%89%E1%85%A5%E1%86%AB%E1%84%92%E1%85%A7%E1%86%BC%20%E1%84%92%E1%85%AC%E1%84%80%E1%85%B1%E1%84%8B%E1%85%AA%20%E1%84%80%E1%85%A1%E1%84%8C%E1%85%AE%E1%86%BC%E1%84%8E%E1%85%B5%20%E1%84%80%E1%85%B2%E1%84%8C%E1%85%A6%20-%20%E1%84%8E%E1%85%AC%E1%84%89%E1%85%A9%E1%84%8C%E1%85%A6%E1%84%80%E1%85%A9%E1%86%B8%20%E1%84%8C%E1%85%A5%E1%86%BC%E1%84%80%E1%85%B2%E1%84%87%E1%85%A1%E1%86%BC%E1%84%8C%E1%85%A5%E1%86%BC%E1%84%89%E1%85%B5%E1%86%A8%2C%20%E1%84%85%E1%85%B5%E1%86%BA%E1%84%8C%E1%85%B5%28Ridge%20L2%29%20%E1%84%86%E1%85%B5%E1%86%BE%20%E1%84%85%E1%85%A1%E1%84%8A%E1%85%A9%28Lasso%20L1%29%20%E1%84%80%E1%85%B2%E1%84%8C%E1%85%A6%20%E1%84%80%E1%85%A8%E1%84%89%E1%85%AE%20.md) - 여러 특성(길이, 높이, 두께 등)을 동시에 사용하는 다중 회귀(Multiple Regression), 고차 다항 변환에 따른 극단적 과대적합(Overfitting), 가중치 벡터 크기를 억제하는 정규화(Regularization) 릿지(Ridge L2 - alpha 파라미터)와 라쏘(Lasso L1), 그리고 로그 스케일 검증 곡선(Validation Curve)을 통한 최적의 규제 강도 알파 튜닝을 인터랙티브 Ridge vs Lasso 규제 강도 시뮬레이터로 학습한다.
* [04. 로지스틱 회귀(Logistic Regression)와 다중 분류 - 시그모이드(Sigmoid), 소프트맥스(Softmax) 및 교차 엔트로피 손실](./04.%20%E1%84%85%E1%85%A9%E1%84%8C%E1%85%B5%E1%84%89%E1%85%B3%E1%84%90%E1%85%B5%E1%86%A8%20%E1%84%92%E1%85%AC%E1%84%80%E1%85%B1%28Logistic%20Regression%29%E1%84%8B%E1%85%AA%20%E1%84%83%E1%85%A1%E1%84%8C%E1%85%AE%E1%86%BC%20%E1%84%87%E1%85%AE%E1%86%AB%E1%84%85%E1%85%B2%20-%20%E1%84%89%E1%85%B5%E1%84%80%E1%85%B3%E1%84%86%E1%85%A9%E1%84%8B%E1%85%B5%E1%84%83%E1%85%B3%28Sigmoid%29%2C%20%E1%84%89%E1%85%A9%E1%84%91%E1%85%B3%E1%84%90%E1%85%B3%E1%84%86%E1%85%A2%E1%86%A8%E1%84%89%E1%85%B3%28Softmax%29%20%E1%84%86%E1%85%B5%E1%86%BE%20%E1%84%80%E1%85%AD%E1%84%8E%E1%85%A1%20%E1%84%8B%E1%85%A6%E1%86%AB%E1%84%90%E1%85%B3%E1%84%85%E1%85%A9%E1%84%91%E1%85%B5%20%E1%84%89%E1%85%A9%E1%86%AB.md) - 선형 회귀의 선형 결합 출력을 확률값([0, 1])으로 사상하는 로지스틱 회귀(Logistic Regression), 이진 분류 시그모이드 함수(Sigmoid / Logistic Function: sigma(z) = 1 / (1 + e^(-z))), 다중 클래스 분류 소프트맥스 함수(Softmax: P(y=k) = e^(z_k) / sum e^(z_j)), 이진 교차 엔트로피(BCE) 손실, 그리고 다중 분류를 위한 One-vs-Rest(OvR) 및 다항 로지스틱 회귀를 인터랙티브 시그모이드 확률 계산기로 학습한다.
* [05. 확률적 경사하강법(SGD)과 점진적 학습 - 온라인 학습(Incremental Learning), 미니배치 SGD, 조기 종료(Early Stopping)](./05.%20%E1%84%92%E1%85%AA%E1%86%A8%E1%84%85%E1%85%B2%E1%86%AF%E1%84%8C%E1%85%A5%E1%86%A8%20%E1%84%80%E1%85%A7%E1%86%BC%E1%84%89%E1%85%A1%E1%84%92%E1%85%A1%E1%84%80%E1%85%A1%E1%86%BC%E1%84%87%E1%85%A5%E1%86%B8%28SGD%29%E1%84%80%E1%85%AA%20%E1%84%8C%E1%85%A5%E1%86%B7%E1%84%8C%E1%85%B5%E1%86%AB%E1%84%8C%E1%85%A5%E1%86%A8%20%E1%84%92%E1%85%A1%E1%86%A8%E1%84%89%E1%85%B3%E1%86%B8%20-%20%E1%84%8B%E1%85%A9%E1%86%AB%E1%84%85%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%AB%20%E1%84%92%E1%85%A1%E1%86%A8%E1%84%89%E1%85%B3%E1%86%B8%28Incremental%20Learning%29%2C%20%E1%84%86%E1%85%B5%E1%84%82%E1%85%B5%E1%84%87%E1%85%A2%E1%84%8E%E1%85%B5%20SGD%2C%20%E1%84%8C%E1%85%A9%E1%84%80%E1%85%B5%20%E1%84%8C%E1%85%A9%E1%86%BC.md) - 메모리에 한 번에 올릴 수 없는 대용량 스트리밍 데이터를 다루는 점진적 학습(Incremental Learning / Online Learning), 확률적 경사하강법(SGD - Stochastic Gradient Descent), 미니배치(Mini-batch) 경사하강법, 손실 함수(log_loss, hinge), 에포크(Epoch) 수와 과대/과소적합의 균형, 그리고 검증 손실 악화 시 학습을 중단하는 조기 종료(Early Stopping) 메커니즘을 인터랙티브 에포크별 손실 곡선 시뮬레이터로 학습한다.
* [06. 의사결정나무(Decision Tree)와 앙상블 기법 - 지니 불순도(Gini), 정보 이득(Information Gain), 가지치기(Pruning)와 특성 중요도](./06.%20%E1%84%8B%E1%85%B4%E1%84%89%E1%85%A1%E1%84%80%E1%85%A7%E1%86%AF%E1%84%8C%E1%85%A5%E1%86%BC%E1%84%82%E1%85%A1%E1%84%86%E1%85%AE%28Decision%20Tree%29%E1%84%8B%E1%85%AA%20%E1%84%8B%E1%85%A1%E1%86%BC%E1%84%89%E1%85%A1%E1%86%BC%E1%84%87%E1%85%B3%E1%86%AF%20%E1%84%80%E1%85%B5%E1%84%87%E1%85%A5%E1%86%B8%20-%20%E1%84%8C%E1%85%B5%E1%84%82%E1%85%B5%20%E1%84%87%E1%85%AE%E1%86%AF%E1%84%89%E1%85%AE%E1%86%AB%E1%84%83%E1%85%A9%28Gini%29%2C%20%E1%84%8C%E1%85%A5%E1%86%BC%E1%84%87%E1%85%A9%20%E1%84%8B%E1%85%B5%E1%84%83%E1%85%B3%E1%86%A8%28Information%20Gain%29%2C%20%E1%84%80%E1%85%A1%E1%84%8C%E1%85%B5%E1%84%8E%E1%85%B5%E1%84%80%E1%85%B5%28Pruning%29%E1%84%8B%E1%85%AA%20.md) - 스무고개 방식으로 데이터를 재귀적으로 이진 분할하는 의사결정나무(Decision Tree), 노드의 순수도를 측정하는 지니 불순도(Gini Impurity: Gini = 1 - sum p_i^2)와 엔트로피(Entropy), 정보 이득(Information Gain) 최대화 분할 기준, 과대적합 방지를 위한 가지치기(Pruning - max_depth, min_samples_split), 특성 중요도(Feature Importance) 계산, 그리고 랜덤 포레스트(Random Forest) 및 그래디언트 부스팅(GBDT) 앙상블로의 확장을 인터랙티브 지니 불순도 계산기로 학습한다.
