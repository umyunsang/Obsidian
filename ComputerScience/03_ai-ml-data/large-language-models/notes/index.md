* [02. 생성형 멀티모달 API 파이프라인 - DALL-E 3 이미지 생성, Whisper 음성 인식 및 TTS 음성 합성](./02.%20%EC%83%9D%EC%84%B1%ED%98%95%20%EB%A9%80%ED%8B%B0%EB%AA%A8%EB%8B%AC%20API%20%ED%8C%8C%EC%9D%B4%ED%94%84%EB%9D%BC%EC%9D%B8%20-%20DALL-E%203%20%EC%9D%B4%EB%AF%B8%EC%A7%80%20%EC%83%9D%EC%84%B1%2C%20Whisper%20%EC%9D%8C%EC%84%B1%20%EC%9D%B8%EC%8B%9D%20%EB%B0%8F%20TTS%20%EC%9D%8C%EC%84%B1%20%ED%95%A9%EC%84%B1.md) - 텍스트를 넘어 시각·청각 모달리티를 통합 처리하는 OpenAI 멀티모달(Multimodal) API 생태계, DALL-E 3의 텍스트 프롬프트 기반 고해상도 이미지 생성·인페인팅(Inpainting)·배리에이션, Whisper 인코더-디코더 트랜스포머 기반의 다국어 음성 인식(STT) 및 타임스탬프 자막 생성, 그리고 자연스러운 음성 합성(TTS - Text-to-Speech)의 스트리밍 오디오 파이프라인을 인터랙티브 멀티모달 워크플로 시뮬레이터로 학습한다.
* [03. 토큰화(Tokenization)와 임베딩(Embedding) - BPE 알고리즘, 고차원 벡터 임베딩과 Faiss 밀집 검색](./03.%20%ED%86%A0%ED%81%B0%ED%99%94%28Tokenization%29%EC%99%80%20%EC%9E%84%EB%B2%A0%EB%94%A9%28Embedding%29%20-%20BPE%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%2C%20%EA%B3%A0%EC%B0%A8%EC%9B%90%20%EB%B2%A1%ED%84%B0%20%EC%9E%84%EB%B2%A0%EB%94%A9%EA%B3%BC%20Faiss%20%EB%B0%80%EC%A7%91%20%EA%B2%80%EC%83%89.md) - 자연어 텍스트를 정수 토큰으로 분할하는 BPE(Byte Pair Encoding - Tiktoken cl100k_base / o200k_base), 텍스트의 의미적 맥락을 고차원 실수 벡터로 투영하는 임베딩 모델(text-embedding-3-small/large), 벡터 공간에서의 코사인 유사도 및 유클리디안 거리 계산, 그리고 수백만 개 고차원 벡터를 초고속 인덱싱·검색하는 Faiss(Facebook AI Similarity Search - FlatL2 vs IndexIVFFlat 클러스터링)를 인터랙티브 Faiss 밀집 검색기로 학습한다.
* [04. LLM 도메인 적응과 파인튜닝(Fine-Tuning) - JSONL 데이터셋 구축, 하이퍼파라미터 최적화와 과적합 방지](./04.%20LLM%20%E1%84%83%E1%85%A9%E1%84%86%E1%85%A6%E1%84%8B%E1%85%B5%E1%86%AB%20%E1%84%8C%E1%85%A5%E1%86%A8%E1%84%8B%E1%85%B3%E1%86%BC%E1%84%80%E1%85%AA%20%E1%84%91%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%90%E1%85%B2%E1%84%82%E1%85%B5%E1%86%BC%28Fine-Tuning%29%20-%20JSONL%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%E1%84%89%E1%85%A6%E1%86%BA%20%E1%84%80%E1%85%AE%E1%84%8E%E1%85%AE%E1%86%A8%2C%20%E1%84%92%E1%85%A1%E1%84%8B%E1%85%B5%E1%84%91%E1%85%A5%E1%84%91%E1%85%A1%E1%84%85%E1%85%A1%E1%84%86%E1%85%B5%E1%84%90%E1%85%A5%20%E1%84%8E%E1%85%AC%E1%84%8C%E1%85%A5%E1%86%A8%E1%84%92%E1%85%AA%E1%84%8B%E1%85%AA%20%E1%84%80%E1%85%AA%E1%84%8C%E1%85%A5%E1%86%A8%E1%84%92%E1%85%A1%E1%86%B8%20%E1%84%87.md) - 사전학습된 거대언어모델을 특정 도메인 맞춤형으로 미세조정하는 OpenAI Fine-Tuning 파이프라인, 프롬프트 엔지니어링 vs RAG vs 파인튜닝의 기술적 트레이드오프, 지도 미세조정(SFT)을 위한 JSONL 대화 데이터셋 구조(Messages: system, user, assistant), 하이퍼파라미터(에포크 수 n_epochs, 배치 크기 batch_size, 학습률 승수 learning_rate_multiplier), 그리고 검증 손실(Validation Loss) 모니터링을 인터랙티브 파인튜닝 수렴 시뮬레이터로 학습한다.
* [05. 검색 증강 생성(RAG) 3단계 파이프라인 - 로딩, 청킹(Chunking), 인덱싱과 생성 아키텍처](./05.%20%EA%B2%80%EC%83%89%20%EC%A6%9D%EA%B0%95%20%EC%83%9D%EC%84%B1%28RAG%29%203%EB%8B%A8%EA%B3%84%20%ED%8C%8C%EC%9D%B4%ED%94%84%EB%9D%BC%EC%9D%B8%20-%20%EB%A1%9C%EB%94%A9%2C%20%EC%B2%AD%ED%82%B9%28Chunking%29%2C%20%EC%9D%B8%EB%8D%B1%EC%8B%B1%EA%B3%BC%20%EC%83%9D%EC%84%B1%20%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98.md) - LLM의 지식 단절(Knowledge Cutoff)과 환각(Hallucination)을 원천 차단하는 검색 증강 생성(RAG, Retrieval-Augmented Generation) 3단계 파이프라인(1단계: 문서 로딩 Document Loading & 재귀적 문자 청킹 RecursiveCharacterTextSplitter, 2단계: 임베딩 및 벡터 저장소 인덱싱 Vector Store Indexing, 3단계: 유사도 검색 및 컨텍스트 주입 생성 Generation)을 인터랙티브 RAG 청킹 파이프라인 시뮬레이터로 학습한다.
* [06. 고급 검색 기법(Advanced Retrieval) - 최대 한계 관련성(MMR), 크로스 인코더 리랭킹(Re-ranking)과 하이브리드 검색](./06.%20%E1%84%80%E1%85%A9%E1%84%80%E1%85%B3%E1%86%B8%20%E1%84%80%E1%85%A5%E1%86%B7%E1%84%89%E1%85%A2%E1%86%A8%20%E1%84%80%E1%85%B5%E1%84%87%E1%85%A5%E1%86%B8%28Advanced%20Retrieval%29%20-%20%E1%84%8E%E1%85%AC%E1%84%83%E1%85%A2%20%E1%84%92%E1%85%A1%E1%86%AB%E1%84%80%E1%85%A8%20%E1%84%80%E1%85%AA%E1%86%AB%E1%84%85%E1%85%A7%E1%86%AB%E1%84%89%E1%85%A5%E1%86%BC%28MMR%29%2C%20%E1%84%8F%E1%85%B3%E1%84%85%E1%85%A9%E1%84%89%E1%85%B3%20%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%8F%E1%85%A9%E1%84%83%E1%85%A5%20%E1%84%85%E1%85%B5%E1%84%85%E1%85%A2%E1%86%BC%E1%84%8F%E1%85%B5%E1%86%BC%28Re-ranking%29%E1%84%80%E1%85%AA%20%E1%84%92%E1%85%A1%E1%84%8B%E1%85%B5%E1%84%87%E1%85%B3%E1%84%85%E1%85%B5%E1%84%83.md) - 단순 코사인 유사도 검색의 중복성 및 단어 불일치 한계를 극복하는 고급 RAG 검색 전략, 다양성과 관련성의 균형을 잡는 MMR(Maximal Marginal Relevance: MMR = argmax [lambda * Sim(d,q) - (1-lambda) * max Sim(d,d_i)]), 바이인코더(Bi-Encoder) 1차 검색 후 고정밀 크로스 인코더(Cross-Encoder)로 순위를 재조정하는 리랭킹(Re-ranking), 그리고 키워드 기반 BM25와 밀집 벡터를 융합하는 하이브리드 검색(Hybrid Search with RRF)을 인터랙티브 MMR 검색기 시뮬레이터로 학습한다.
