* [05. 데이터 통계 기초와 탐색적 데이터 분석(EDA) - 기술 통계량, 가설검정(t-test·ANOVA)과 상관계수](./05.%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%20%E1%84%90%E1%85%A9%E1%86%BC%E1%84%80%E1%85%A8%20%E1%84%80%E1%85%B5%E1%84%8E%E1%85%A9%E1%84%8B%E1%85%AA%20%E1%84%90%E1%85%A1%E1%86%B7%E1%84%89%E1%85%A2%E1%86%A8%E1%84%8C%E1%85%A5%E1%86%A8%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%20%E1%84%87%E1%85%AE%E1%86%AB%E1%84%89%E1%85%A5%E1%86%A8%28EDA%29%20-%20%E1%84%80%E1%85%B5%E1%84%89%E1%85%AE%E1%86%AF%20%E1%84%90%E1%85%A9%E1%86%BC%E1%84%80%E1%85%A8%E1%84%85%E1%85%A3%E1%86%BC%2C%20%E1%84%80%E1%85%A1%E1%84%89%E1%85%A5%E1%86%AF%E1%84%80%E1%85%A5%E1%86%B7%E1%84%8C%E1%85%A5%E1%86%BC%28t-test%C2%B7ANOVA%29%E1%84%80%E1%85%AA%20%E1%84%89%E1%85%A1%E1%86%BC%E1%84%80%E1%85%AA%E1%86%AB%E1%84%80%E1%85%A8.md) - 빅데이터 전처리와 모델링의 기반이 되는 기술 통계량(평균, 중앙값, 분산, 왜도, 첨도), 정규분포 중심극한정리(CLT), 귀무가설($H_0$)과 대립가설($H_1$), p-value 유의수준 판정, 2개 이상 집단 비교를 위한 독립표본 t-test 및 일원배치 분산분석(ANOVA - F-통계량: $F = MS_{between} / MS_{within}$), 그리고 피어슨/스피어만 상관계수를 인터랙티브 가설검정 p-value 계산기로 학습한다.
* [06. 고차원 변수 선택(Variable Selection) 기법 - 필터링·래퍼·임베디드(Lasso·Ridge)와 다중공선성(VIF)](./06.%20%EA%B3%A0%EC%B0%A8%EC%9B%90%20%EB%B3%80%EC%88%98%20%EC%84%A0%ED%83%9D%28Variable%20Selection%29%20%EA%B8%B0%EB%B2%95%20-%20%ED%95%84%ED%84%B0%EB%A7%81%C2%B7%EB%9E%98%ED%8D%BC%C2%B7%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%28Lasso%C2%B7Ridge%29%EC%99%80%20%EB%8B%A4%EC%A4%91%EA%B3%B5%EC%84%A0%EC%84%B1%28VIF%29.md) - 고차원 빅데이터에서 차원의 저주(Curse of Dimensionality)와 과적합을 방지하는 변수 선택 3대 방법론(1. Filter - 카이제곱, ANOVA F, 상호정보량 Mutual Information, 2. Wrapper - 전진선택, 후진소거, 단계적 선택, 3. Embedded - L1 Lasso 정규화 $lambda |w|_1$, L2 Ridge 정규화 $lambda |w|_2^2$, ElasticNet), 그리고 독립변수 간 강한 상관관계로 인한 왜곡을 진단하는 분산팽창지수(VIF: $VIF_j = frac{1}{1 - R_j^2}$)를 인터랙티브 L1 vs L2 정규화 시뮬레이터로 학습한다.
* [07. 스트리밍 데이터 알고리즘과 실시간 처리 - Data without Disk, Flajolet-Martin 카디널리티와 Count-Min Sketch](./07.%20%EC%8A%A4%ED%8A%B8%EB%A6%AC%EB%B0%8D%20%EB%8D%B0%EC%9D%B4%ED%84%B0%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%EA%B3%BC%20%EC%8B%A4%EC%8B%9C%EA%B0%84%20%EC%B2%98%EB%A6%AC%20-%20Data%20without%20Disk%2C%20Flajolet-Martin%20%EC%B9%B4%EB%94%94%EB%84%90%EB%A6%AC%ED%8B%B0%EC%99%80%20Count-Min%20Sketch.md) - 디스크 저장 없이 단 한 번의 순회(Single Pass)와 극도로 제한된 $O(text{polylog } N)$ 메모리로 방대한 데이터 스트림을 분석하는 스트리밍 알고리즘(Streaming Algorithms), 서로 다른 원소 개수를 추정하는 Flajolet-Martin(FM / HyperLogLog) 카디널리티 알고리즘, 빈도수를 추정하는 Count-Min Sketch(해시 함수 $d$개와 2차원 배열), 그리고 슬라이딩 윈도우(Sliding Window) 기반 DGIM 알고리즘을 인터랙티브 Flajolet-Martin 카디널리티 계산기로 학습한다.
* [08. 다목적 최적화(Multi-Objective Optimization)와 파레토 프론트 - 파레토 지배(Pareto Dominance)와 NSGA-II 유전 알고리즘](./08.%20%EB%8B%A4%EB%AA%A9%EC%A0%81%20%EC%B5%9C%EC%A0%81%ED%99%94%28Multi-Objective%20Optimization%29%EC%99%80%20%ED%8C%8C%EB%A0%88%ED%86%A0%20%ED%94%84%EB%A1%A0%ED%8A%B8%20-%20%ED%8C%8C%EB%A0%88%ED%86%A0%20%EC%A7%80%EB%B0%B0%28Pareto%20Dominance%29%EC%99%80%20NSGA-II%20%EC%9C%A0%EC%A0%84%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98.md) - 상충(Trade-off)하는 복수의 목적 함수를 동시에 최적화하는 다목적 최적화(MOO, Multi-Objective Optimization), 파레토 지배(Pareto Dominance: $u > v <=> forall i, f_i(u) <= f_i(v) and exists j, f_j(u) < f_j(v)$)와 파레토 프론트(Pareto Front), 단일 목적 가중합(Weighted Sum) 방식의 볼록성 한계, 그리고 비지배 분류 및 혼잡도 거리(Crowding Distance)를 활용하는 NSGA-II 유전 알고리즘을 인터랙티브 2목적 파레토 지배 판정기로 학습한다.
