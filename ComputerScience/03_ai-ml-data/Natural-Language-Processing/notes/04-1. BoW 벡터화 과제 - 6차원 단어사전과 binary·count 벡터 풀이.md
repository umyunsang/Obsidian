> [!NOTE]
> **과제** — BoW 모델을 이용해 아래 세 문서의 벡터를 구하시오.
>
> - 문서1: `i love machine learning`
> - 문서2: `i love deep deep learning learning`
> - 문서3: `i like deep learning`
>
> 개념 설명과 TF-IDF 확장은 [04. BoW와 TF-IDF](./04.%20BoW%EC%99%80%20TF-IDF%20-%20%EB%AC%B8%EC%84%9C%20%EB%B2%A1%ED%84%B0%ED%99%94%2C%20%EC%9D%B4%EC%A7%84%C2%B7%EB%B9%88%EB%8F%84%20%EB%8B%A8%EC%96%B4%EA%B0%80%EB%B0%A9%20%EB%AA%A8%EB%8D%B8%EA%B3%BC%20%EB%91%90%20%EA%B0%80%EC%A7%80%20TF-IDF%20%EA%B3%84%EC%82%B0%EB%B2%95.md) 에 정리되어 있다.

## 1단계 — 단어사전 구하기 (차원 결정)

세 문서에 등장하는 단어를 모두 모은 뒤 **중복을 제거하고 정렬**한다.

- 문서1 → `i` `love` `machine` `learning`
- 문서2 → `i` `love` `deep` `deep` `learning` `learning`
- 문서3 → `i` `like` `deep` `learning`

합치면 `i` `love` `machine` `learning` `deep` `like` — 중복 제거 후 **6종류**다. 알파벳순으로 정렬하면:

```text
인덱스   0       1    2           3       4       5
단어    deep    i    learning    like    love    machine
```

> [!IMPORTANT]
> 단어가 6종류이므로 **모든 문서는 6차원 벡터**로 표현된다. 사전의 $i$번째 단어가 벡터의 $i$번째 자리이므로, **사전 순서를 먼저 고정**해야 세 벡터를 서로 비교할 수 있다.

## 2단계 — binary BoW (등장 여부만 0/1)

각 단어가 그 문서에 **있으면 1, 없으면 0**. 몇 번 나왔든 상관없다.

- **문서1** `i love machine learning` — `deep` 없음, `like` 없음

  ```text
  [0, 1, 1, 0, 1, 1]
  ```

- **문서2** `i love deep deep learning learning` — `like` 없음, `machine` 없음

  ```text
  [1, 1, 1, 0, 1, 0]
  ```

- **문서3** `i like deep learning` — `love` 없음, `machine` 없음

  ```text
  [1, 1, 1, 1, 0, 0]
  ```

## 3단계 — count BoW (등장 횟수)

각 단어가 그 문서에 **몇 번 나왔는지**를 그대로 적는다.

- **문서1** — 중복 단어 없음, binary와 동일

  ```text
  [0, 1, 1, 0, 1, 1]
  ```

- **문서2** — ==`deep` 2회, `learning` 2회== 이 값으로 드러난다

  ```text
  [2, 1, 2, 0, 1, 0]
  ```

- **문서3** — 중복 단어 없음, binary와 동일

  ```text
  [1, 1, 1, 1, 0, 0]
  ```

> [!TIP]
> **두 방식이 갈라지는 곳은 문서2뿐이다.** 문서1·문서3은 같은 단어가 두 번 나오지 않아 binary와 count가 완전히 같다. 즉 **중복 단어가 없는 문서라면 두 표현은 구분되지 않는다.**
>
> 문서2만 `[1,1,1,0,1,0]` → `[2,1,2,0,1,0]` 으로 바뀌면서 "이 문서는 deep과 learning을 강조하고 있다"는 정보가 살아남는다.

<summary>파이썬 검산 코드</summary>

```python
from sklearn.feature_extraction.text import CountVectorizer
import pandas as pd

docs = [
    "i love machine learning",
    "i love deep deep learning learning",
    "i like deep learning"
]

# 1글자 단어 'i' 를 살리려면 token_pattern 을 바꿔야 한다
pat = r"(?u)\b\w+\b"

print("[binary BoW]")
bv = CountVectorizer(token_pattern=pat, binary=True)
print(pd.DataFrame(bv.fit_transform(docs).toarray(), columns=bv.get_feature_names_out()))

print("\n[count BoW]")
cv = CountVectorizer(token_pattern=pat)
print(pd.DataFrame(cv.fit_transform(docs).toarray(), columns=cv.get_feature_names_out()))
```

> [!WARNING]
> `token_pattern` 을 지정하지 않으면 싸이킷런 기본값이 **2글자 이상**만 토큰으로 잡아 `i` 가 통째로 버려진다. 그러면 단어사전이 5개로 줄어 정답과 달라진다.

## 관찰 포인트

- **`i` 와 `learning` 은 세 문서 전부에 등장한다** ($df = 3$). 모든 문서를 구분하지 못하므로 변별력이 없다 — 다음 단계인 TF-IDF에서 IDF가 가장 낮게 깎일 후보다.
- **`machine` 과 `like` 는 한 문서에만 등장한다** ($df = 1$). 각각 문서1과 문서3을 특정하는 가장 강한 단서다.
- **문서2와 문서3은 binary로 보면 꽤 비슷하다** — `deep`·`i`·`learning` 을 공유하고 `love`/`like` 에서만 갈라진다. count로 바꾸면 문서2의 강조가 드러나 거리가 벌어진다.
- **대소문자는 소문자로 통일**했다. 통일하지 않으면 `I` 와 `i` 가 별도 차원이 되어 차원만 늘어난다.

> [!NOTE]
> 순서 정보는 두 방식 모두에서 사라진다. `i love deep deep learning learning` 을 어떻게 섞어도 같은 벡터가 나온다 — 이것이 단어가방 모델의 근본 한계다.
