* [01. 생성형 AI 생태계와 멀티모달 디자인 혁신 - 파운데이션 모델, T2I 확산 모델과 인터페이스 제어](./01.%20%E1%84%89%E1%85%A2%E1%86%BC%E1%84%89%E1%85%A5%E1%86%BC%E1%84%92%E1%85%A7%E1%86%BC%20AI%20%E1%84%89%E1%85%A2%E1%86%BC%E1%84%90%E1%85%A2%E1%84%80%E1%85%A8%E1%84%8B%E1%85%AA%20%E1%84%86%E1%85%A5%E1%86%AF%E1%84%90%E1%85%B5%E1%84%86%E1%85%A9%E1%84%83%E1%85%A1%E1%86%AF%20%E1%84%83%E1%85%B5%E1%84%8C%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%AB%20%E1%84%92%E1%85%A7%E1%86%A8%E1%84%89%E1%85%B5%E1%86%AB%20-%20%E1%84%91%E1%85%A1%E1%84%8B%E1%85%AE%E1%86%AB%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%89%E1%85%A7%E1%86%AB%20%E1%84%86%E1%85%A9%E1%84%83%E1%85%A6%E1%86%AF%2C%20T2I%20%E1%84%92%E1%85%AA%E1%86%A8%E1%84%89%E1%85%A1%E1%86%AB%20%E1%84%86%E1%85%A9%E1%84%83%E1%85%A6%E1%86%AF%E1%84%80%E1%85%AA%20%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%90%E1%85%A5.md) - 텍스트·이미지·3D를 아우르는 생성형 AI(Generative AI)의 발전사, 파운데이션 모델(Foundation Models)의 스케일링 법칙, Text-to-Image(T2I) 잠재 확산 모델(Latent Diffusion Models - Stable Diffusion), 멀티모달 프롬프트 엔지니어링, 그리고 건축·제품·엔터테인먼트 산업에서의 비주얼 디자인 탐색 워크플로를 인터랙티브 잠재 확산 노이즈 제거 시뮬레이터로 학습한다.
* [02. 매개변수 효율적 미세조정(PEFT)과 LoRA 수학적 원리 - 저차원 행렬 분해(W = W0 + BA), 랭크 r과 스케일링 알파](./02.%20%E1%84%86%E1%85%A2%E1%84%80%E1%85%A2%E1%84%87%E1%85%A7%E1%86%AB%E1%84%89%E1%85%AE%20%E1%84%92%E1%85%AD%E1%84%8B%E1%85%B2%E1%86%AF%E1%84%8C%E1%85%A5%E1%86%A8%20%E1%84%86%E1%85%B5%E1%84%89%E1%85%A6%E1%84%8C%E1%85%A9%E1%84%8C%E1%85%A5%E1%86%BC%28PEFT%29%E1%84%80%E1%85%AA%20LoRA%20%E1%84%89%E1%85%AE%E1%84%92%E1%85%A1%E1%86%A8%E1%84%8C%E1%85%A5%E1%86%A8%20%E1%84%8B%E1%85%AF%E1%86%AB%E1%84%85%E1%85%B5%20-%20%E1%84%8C%E1%85%A5%E1%84%8E%E1%85%A1%E1%84%8B%E1%85%AF%E1%86%AB%20%E1%84%92%E1%85%A2%E1%86%BC%E1%84%85%E1%85%A7%E1%86%AF%20%E1%84%87%E1%85%AE%E1%86%AB%E1%84%92%E1%85%A2%28W%20%3D%20W0%20%2B%20BA%29%2C%20%E1%84%85%E1%85%A2%E1%86%BC%E1%84%8F%E1%85%B3%20r%E1%84%80%E1%85%AA%20%E1%84%89%E1%85%B3%E1%84%8F%E1%85%A6.md) - 거대언어모델 및 확산 모델의 전체 가중치 파인튜닝(Full Fine-Tuning)의 엄청난 메모리 비용을 해결하는 PEFT(Parameter-Efficient Fine-Tuning), 저차원 행렬 분해 LoRA(Low-Rank Adaptation: W = W0 + Delta W = W0 + (alpha / r) * B * A, B in R^(d x r), A in R^(r x k), r << min(d,k)), 랭크 r과 스케일링 팩터 alpha의 수학적 상호작용, 그리고 추론 시 서빙 오버헤드가 전혀 없는 Zero Inference Latency 병합 공식을 인터랙티브 LoRA 파라미터 절감 계산기로 학습한다.
* [03. 이미지 생성 모델 LoRA 학습과 실전 튜닝 - Stable Diffusion Checkpoint, 캡셔닝 태깅과 체크포인트 병합](./03.%20%E1%84%8B%E1%85%B5%E1%84%86%E1%85%B5%E1%84%8C%E1%85%B5%20%E1%84%89%E1%85%A2%E1%86%BC%E1%84%89%E1%85%A5%E1%86%BC%20%E1%84%86%E1%85%A9%E1%84%83%E1%85%A6%E1%86%AF%20LoRA%20%E1%84%92%E1%85%A1%E1%86%A8%E1%84%89%E1%85%B3%E1%86%B8%E1%84%80%E1%85%AA%20%E1%84%89%E1%85%B5%E1%86%AF%E1%84%8C%E1%85%A5%E1%86%AB%20%E1%84%90%E1%85%B2%E1%84%82%E1%85%B5%E1%86%BC%20-%20Stable%20Diffusion%20Checkpoint%2C%20%E1%84%8F%E1%85%A2%E1%86%B8%E1%84%89%E1%85%A7%E1%84%82%E1%85%B5%E1%86%BC%20%E1%84%90%E1%85%A2%E1%84%80%E1%85%B5%E1%86%BC%E1%84%80%E1%85%AA%20%E1%84%8E%E1%85%A6%E1%84%8F%E1%85%B3%E1%84%91%E1%85%A9%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%90%E1%85%B3%20%E1%84%87%E1%85%A7%E1%86%BC%E1%84%92%E1%85%A1.md) - Stable Diffusion WebUI 및 Kohya-ss 기반 이미지 LoRA 학습 실전 파이프라인, 고품질 데이터셋 구축(해상도 512/1024 버킷팅, 이미지 크롭 및 정제), 자동 캡셔닝(BLIP / WD14 Tagger)과 트리거 워드(Trigger Word) 주입, 네트워크 랭크(Network Dim / Alpha) 및 학습률(UNet LR vs TE LR) 설정, 그리고 다양한 화풍/캐릭터 어댑터를 결합하는 가중치 병합(LoRA Merge & Weight Blending)을 인터랙티브 LoRA 가중치 블렌더 시뮬레이터로 학습한다.
* [04. 산업 디자인 및 엔지니어링 생성 설계(Generative Design) - CAD·CAE 통합 3D 형상 생성과 성능 최적화](./04.%20%E1%84%89%E1%85%A1%E1%86%AB%E1%84%8B%E1%85%A5%E1%86%B8%20%E1%84%83%E1%85%B5%E1%84%8C%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%AB%20%E1%84%86%E1%85%B5%E1%86%BE%20%E1%84%8B%E1%85%A6%E1%86%AB%E1%84%8C%E1%85%B5%E1%84%82%E1%85%B5%E1%84%8B%E1%85%A5%E1%84%85%E1%85%B5%E1%86%BC%20%E1%84%89%E1%85%A2%E1%86%BC%E1%84%89%E1%85%A5%E1%86%BC%20%E1%84%89%E1%85%A5%E1%86%AF%E1%84%80%E1%85%A8%28Generative%20Design%29%20-%20CAD%C2%B7CAE%20%E1%84%90%E1%85%A9%E1%86%BC%E1%84%92%E1%85%A1%E1%86%B8%203D%20%E1%84%92%E1%85%A7%E1%86%BC%E1%84%89%E1%85%A1%E1%86%BC%20%E1%84%89%E1%85%A2%E1%86%BC%E1%84%89%E1%85%A5%E1%86%BC%E1%84%80%E1%85%AA%20%E1%84%89%E1%85%A5%E1%86%BC%E1%84%82%E1%85%B3%E1%86%BC%20%E1%84%8E%E1%85%AC%E1%84%8C.md) - 전통적 CAD 설계를 혁신하는 딥러닝 기반 산업 생성 설계(Generative Design), 기아(KIA) 자동차 휠 디자인 및 섀시 부품의 3D 콘셉트 생성 사례, 유한요소해석(FEA) 및 구조 역학 시뮬레이션(CAE)과의 결합을 통한 강성 극대화 및 중량 최소화 다목적 최적화, 그리고 딥러닝 3D 메시 복셀(Voxel) 표상 기술을 인터랙티브 구조 최적화 시뮬레이터로 학습한다.
* [05. 강화학습(RL) 기반 피드백 정렬과 생성형 디자인의 미래 - DPO, PPO 인간 피드백 및 최신 생성 모델](./05.%20%E1%84%80%E1%85%A1%E1%86%BC%E1%84%92%E1%85%AA%E1%84%92%E1%85%A1%E1%86%A8%E1%84%89%E1%85%B3%E1%86%B8%28RL%29%20%E1%84%80%E1%85%B5%E1%84%87%E1%85%A1%E1%86%AB%20%E1%84%91%E1%85%B5%E1%84%83%E1%85%B3%E1%84%87%E1%85%A2%E1%86%A8%20%E1%84%8C%E1%85%A5%E1%86%BC%E1%84%85%E1%85%A7%E1%86%AF%E1%84%80%E1%85%AA%20%E1%84%89%E1%85%A2%E1%86%BC%E1%84%89%E1%85%A5%E1%86%BC%E1%84%92%E1%85%A7%E1%86%BC%20%E1%84%83%E1%85%B5%E1%84%8C%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%8B%E1%85%B4%20%E1%84%86%E1%85%B5%E1%84%85%E1%85%A2%20-%20DPO%2C%20PPO%20%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%80%E1%85%A1%E1%86%AB%20%E1%84%91%E1%85%B5%E1%84%83%E1%85%B3%E1%84%87%E1%85%A2%E1%86%A8%20%E1%84%86%E1%85%B5%E1%86%BE%20%E1%84%8E%E1%85%AC%E1%84%89%E1%85%B5%E1%86%AB%20.md) - 생성 모델의 결과물을 인간의 가치관 및 물리적 미학 기준에 일치시키는 정렬(Alignment) 기술, RLHF(Reinforcement Learning from Human Feedback - 보상 모델 Reward Model & PPO), 보상 모델 없이 직접 선호도를 최적화하는 DPO(Direct Preference Optimization: L_DPO = -E[log sigma(beta log (pi_theta / pi_ref))]), 그리고 자율형 멀티모달 디자인 에이전트로의 진화 방향을 인터랙티브 DPO 손실 계산기로 학습한다.
