* [01. 프로그래밍 언어 평가 기준과 번역 패러다임 - 직교성(Orthogonality), 컴파일러·인터프리터와 JIT 하이브리드](./01.%20%E1%84%91%E1%85%B3%E1%84%85%E1%85%A9%E1%84%80%E1%85%B3%E1%84%85%E1%85%A2%E1%84%86%E1%85%B5%E1%86%BC%20%E1%84%8B%E1%85%A5%E1%86%AB%E1%84%8B%E1%85%A5%20%E1%84%91%E1%85%A7%E1%86%BC%E1%84%80%E1%85%A1%20%E1%84%80%E1%85%B5%E1%84%8C%E1%85%AE%E1%86%AB%E1%84%80%E1%85%AA%20%E1%84%87%E1%85%A5%E1%86%AB%E1%84%8B%E1%85%A7%E1%86%A8%20%E1%84%91%E1%85%A2%E1%84%85%E1%85%A5%E1%84%83%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%B7%20-%20%E1%84%8C%E1%85%B5%E1%86%A8%E1%84%80%E1%85%AD%E1%84%89%E1%85%A5%E1%86%BC%28Orthogonality%29%2C%20%E1%84%8F%E1%85%A5%E1%86%B7%E1%84%91%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%AF%E1%84%85%E1%85%A5%C2%B7%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%90%E1%85%A5%E1%84%91%E1%85%B3%E1%84%85%E1%85%B5%E1%84%90%E1%85%A5%E1%84%8B.md) - 프로그래밍 언어 설계 및 평가 4대 기준(가독성 Readability, 작성력 Writability, 신뢰성 Reliability, 비용 Cost), 언어의 직교성(Orthogonality) 개념, 소스 코드를 기계어로 번역하는 컴파일러(Compiler - 어휘/구문/의미 분석, 중간 코드 생성, 최적화), 인터프리터(Interpreter)의 동적 실행과 한계, 그리고 Java/C#의 가상머신(JVM/CLR) 바이트코드 및 JIT(Just-In-Time) 하이브리드 실행 아키텍처를 인터랙티브 언어 번역 패러다임 비교기로 학습한다.
* [02. 형식 문법과 구문론(Syntax) - BNF·EBNF 표기법, 파스 트리(Parse Tree)와 문법 모호성](./02.%20%ED%98%95%EC%8B%9D%20%EB%AC%B8%EB%B2%95%EA%B3%BC%20%EA%B5%AC%EB%AC%B8%EB%A1%A0%28Syntax%29%20-%20BNF%C2%B7EBNF%20%ED%91%9C%EA%B8%B0%EB%B2%95%2C%20%ED%8C%8C%EC%8A%A4%20%ED%8A%B8%EB%A6%AC%28Parse%20Tree%29%EC%99%80%20%EB%AC%B8%EB%B2%95%20%EB%AA%A8%ED%98%B8%EC%84%B1.md) - 언어의 형식을 정의하는 구문론(Syntax)과 의미를 정의하는 의미론(Semantics), 콘텍스트 자유 문법(CFG, Context-Free Grammar)과 촘스키 2형 계층, 배커스-나우르 표기법(BNF) 및 확장 BNF(EBNF - 선택 [], 반복 {}, 그룹 ()), 유도(Derivation: 최좌단 Leftmost vs 최우단 Rightmost), 파스 트리(Parse Tree) 구축, 동일 문장에 대해 서로 다른 파스 트리가 생성되는 문법의 모호성(Ambiguity) 증명 및 연산자 우선순위/결합법칙 규칙 부여를 인터랙티브 BNF 파스 트리 평가기로 학습한다.
* [03. 이름(Names), 바인딩(Binding)과 수명(Lifetime) - 정적·동적 바인딩, 스택-동적과 힙-동적 할당](./03.%20%EC%9D%B4%EB%A6%84%28Names%29%2C%20%EB%B0%94%EC%9D%B8%EB%94%A9%28Binding%29%EA%B3%BC%20%EC%88%98%EB%AA%85%28Lifetime%29%20-%20%EC%A0%95%EC%A0%81%C2%B7%EB%8F%99%EC%A0%81%20%EB%B0%94%EC%9D%B8%EB%94%A9%2C%20%EC%8A%A4%ED%83%9D-%EB%8F%99%EC%A0%81%EA%B3%BC%20%ED%9E%99-%EB%8F%99%EC%A0%81%20%ED%95%A0%EB%8B%B9.md) - 프로그래밍 언어의 기본 구성요소인 변수의 6대 속성(이름 Name, 메모리 주소 Address, 데이터 타입 Type, 저장된 값 Value, 수명 Lifetime, 유효 영역 Scope), 바인딩 시간(Binding Time: 언어 설계, 언어 구현, 컴파일, 링크, 로드, 런타임), 정적 바인딩(Static Binding) vs 동적 바인딩(Dynamic Binding), 그리고 변수 수명에 따른 4대 메모리 할당 범주(1. 정적 변수 Static, 2. 스택-동적 변수 Stack-dynamic, 3. 명시적 힙-동적 Explicit Heap, 4. 묵시적 힙-동적 변수)를 인터랙티브 변수 수명 및 바인딩 시뮬레이터로 학습한다.
* [04. 정적 영역(Static Scope)과 동적 영역(Dynamic Scope) - 스코프 체인, 참조 환경과 비국소 변수 탐색](./04.%20%EC%A0%95%EC%A0%81%20%EC%98%81%EC%97%AD%28Static%20Scope%29%EA%B3%BC%20%EB%8F%99%EC%A0%81%20%EC%98%81%EC%97%AD%28Dynamic%20Scope%29%20-%20%EC%8A%A4%EC%BD%94%ED%94%84%20%EC%B2%B4%EC%9D%B8%2C%20%EC%B0%B8%EC%A1%B0%20%ED%99%98%EA%B2%BD%EA%B3%BC%20%EB%B9%84%EA%B5%AD%EC%86%8C%20%EB%B3%80%EC%88%98%20%ED%83%90%EC%83%89.md) - 변수의 유효 범위(Scope)와 참조 환경(Referencing Environment), 소스 코드의 텍스트 구조 및 블록 중첩에 의해 결정되는 정적 영역(Static / Lexical Scope), 함수 호출 순서(Call Stack)에 따라 런타임에 결정되는 동적 영역(Dynamic Scope), 스코프 체인(Static Link vs Dynamic Link)을 통한 비국소 변수(Nonlocal Variable) 탐색 알고리즘, 영역 구멍(Scope Hole / Shadowing), 그리고 클로저(Closure)의 캡처 원리를 인터랙티브 정적 vs 동적 스코프 탐색 시뮬레이터로 학습한다.
* [05. 데이터 타입 시스템과 메모리 모델 - 배열 주소 사상 공식, 타입 동치성과 댕글링 포인터](./05.%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%20%E1%84%90%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%B8%20%E1%84%89%E1%85%B5%E1%84%89%E1%85%B3%E1%84%90%E1%85%A6%E1%86%B7%E1%84%80%E1%85%AA%20%E1%84%86%E1%85%A6%E1%84%86%E1%85%A9%E1%84%85%E1%85%B5%20%E1%84%86%E1%85%A9%E1%84%83%E1%85%A6%E1%86%AF%20-%20%E1%84%87%E1%85%A2%E1%84%8B%E1%85%A7%E1%86%AF%20%E1%84%8C%E1%85%AE%E1%84%89%E1%85%A9%20%E1%84%89%E1%85%A1%E1%84%89%E1%85%A1%E1%86%BC%20%E1%84%80%E1%85%A9%E1%86%BC%E1%84%89%E1%85%B5%E1%86%A8%2C%20%E1%84%90%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%B8%20%E1%84%83%E1%85%A9%E1%86%BC%E1%84%8E%E1%85%B5%E1%84%89%E1%85%A5%E1%86%BC%E1%84%80%E1%85%AA%20%E1%84%83%E1%85%A2%E1%86%BC%E1%84%80%E1%85%B3%E1%86%AF%E1%84%85%E1%85%B5%E1%86%BC%20%E1%84%91%E1%85%A9.md) - 기본 원시 데이터 타입과 사용자 정의 복합 타입, 다차원 배열의 메모리 주소 사상 함수(행 우선 Row-Major vs 열 우선 Column-Major 주소 계산 공식), 레코드 구조체와 메모리 패딩(Padding/Alignment), 공용체(Union)의 안전성, 포인터 연산으로 인한 메모리 안전성 결함(댕글링 포인터 Dangling Pointer, 메모리 누수 Memory Leak, 톰스톤 Tombstone vs 락-앤-키 Lock-and-Key 보호 기법), 그리고 타입 동치성(구조적 동치 Structural vs 이름 동치 Name Equivalence)을 인터랙티브 2D 배열 주소 계산기로 학습한다.
