## lecture

* [01. 데이터베이스 시스템과 3단계 아키텍처 - 데이터 독립성(논리적·물리적), 3단계 스키마와 DBMS 엔진 구조](./01.%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%E1%84%87%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%89%E1%85%B3%20%E1%84%89%E1%85%B5%E1%84%89%E1%85%B3%E1%84%90%E1%85%A6%E1%86%B7%E1%84%80%E1%85%AA%203%E1%84%83%E1%85%A1%E1%86%AB%E1%84%80%E1%85%A8%20%E1%84%8B%E1%85%A1%E1%84%8F%E1%85%B5%E1%84%90%E1%85%A6%E1%86%A8%E1%84%8E%E1%85%A5%20-%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%20%E1%84%83%E1%85%A9%E1%86%A8%E1%84%85%E1%85%B5%E1%86%B8%E1%84%89%E1%85%A5%E1%86%BC%28%E1%84%82%E1%85%A9%E1%86%AB%E1%84%85%E1%85%B5%E1%84%8C%E1%85%A5%E1%86%A8%C2%B7%E1%84%86%E1%85%AE%E1%86%AF%E1%84%85%E1%85%B5%E1%84%8C%E1%85%A5%E1%86%A8%29%2C%203%E1%84%83%E1%85%A1%E1%86%AB%E1%84%80%E1%85%A8%20%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B5%E1%84%86%E1%85%A1.md) - 파일 시스템의 데이터 종속성과 중복성 한계, ANSI/SPARC 3단계 데이터베이스 구조(1. 외부 스키마 External, 2. 개념 스키마 Conceptual, 3. 내부 스키마 Internal), 논리적 데이터 독립성(Logical Data Independence)과 물리적 데이터 독립성(Physical Data Independence), 데이터 사전(Data Dictionary / 시스템 카탈로그)과 메타데이터, 그리고 질의 처리기(Query Processor) 및 저장 엔진(Storage Engine)의 핵심 구성요소를 인터랙티브 3단계 스키마 독립성 시뮬레이터로 학습한다.
* [02. 개념적 데이터 모델링과 E-R 모델 - 개체-관계 다이어그램(ERD), 카디널리티(1:1, 1:N, N:M)와 식별자](./02.%20%EA%B0%9C%EB%85%90%EC%A0%81%20%EB%8D%B0%EC%9D%B4%ED%84%B0%20%EB%AA%A8%EB%8D%B8%EB%A7%81%EA%B3%BC%20E-R%20%EB%AA%A8%EB%8D%B8%20-%20%EA%B0%9C%EC%B2%B4-%EA%B4%80%EA%B3%84%20%EB%8B%A4%EC%9D%B4%EC%96%B4%EA%B7%B8%EB%9E%A8%28ERD%29%2C%20%EC%B9%B4%EB%94%94%EB%84%90%EB%A6%AC%ED%8B%B0%281%3A1%2C%201%3AN%2C%20N%3AM%29%EC%99%80%20%EC%8B%9D%EB%B3%84%EC%9E%90.md) - 요구사항 분석에서 개념적 설계를 도출하는 데이터 모델링 파이프라인, 피터 첸(Peter Chen) 및 IE(Crow's Foot) 표기법 개체-관계(E-R) 모델, 개체(Entity - 강한 개체 vs 약한 개체), 속성(Attribute - 단순/복합, 단일/다치, 유도 속성), 관계(Relationship)와 구조적 제약조건(참여 제약조건: 필수/선택, 카디널리티 비율: 1:1, 1:N, N:M), 그리고 기본키(PK)와 외래키(FK)를 인터랙티브 ERD 카디널리티 검증기로 학습한다.
* [03. 관계 데이터 모델과 관계 대수 - 릴레이션 제약조건(개체·참조 무결성)과 순수 관계 연산자(σ, π, ⨝, ÷)](./03.%20%E1%84%80%E1%85%AA%E1%86%AB%E1%84%80%E1%85%A8%20%E1%84%83%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%90%E1%85%A5%20%E1%84%86%E1%85%A9%E1%84%83%E1%85%A6%E1%86%AF%E1%84%80%E1%85%AA%20%E1%84%80%E1%85%AA%E1%86%AB%E1%84%80%E1%85%A8%20%E1%84%83%E1%85%A2%E1%84%89%E1%85%AE%20-%20%E1%84%85%E1%85%B5%E1%86%AF%E1%84%85%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%89%E1%85%A7%E1%86%AB%20%E1%84%8C%E1%85%A6%E1%84%8B%E1%85%A3%E1%86%A8%E1%84%8C%E1%85%A9%E1%84%80%E1%85%A5%E1%86%AB%28%E1%84%80%E1%85%A2%E1%84%8E%E1%85%A6%C2%B7%E1%84%8E%E1%85%A1%E1%86%B7%E1%84%8C%E1%85%A9%20%E1%84%86%E1%85%AE%E1%84%80%E1%85%A7%E1%86%AF%E1%84%89%E1%85%A5%E1%86%BC%29%E1%84%80%E1%85%AA%20%E1%84%89%E1%85%AE%E1%86%AB%E1%84%89%E1%85%AE%20%E1%84%80%E1%85%AA%E1%86%AB%E1%84%80%E1%85%A8%20%E1%84%8B.md) - E.F. Codd가 제안한 관계 데이터 모델(Relational Data Model)의 수학적 기초(튜플, 도메인, 차수 Degree, 카디널리티 Cardinality), 릴레이션 3대 무결성 제약조건(1. 개체 무결성 Entity Integrity, 2. 참조 무결성 Referential Integrity - CASCADE/SET NULL, 3. 도메인 무결성), 그리고 순수 관계 연산자(선택 Select sigma, 투영 Project pi, 조인 Join bowtie - 세타/동등/자연조인, 디비전 Division divide) 및 일반 집합 연산자를 인터랙티브 관계 대수 연산 시뮬레이터로 학습한다.
* [04. 구조적 질의 언어(SQL)와 고급 쿼리 최적화 - DDL·DML·DCL, 서브쿼리, 조인 알고리즘과 실행 계획](./04.%20%EA%B5%AC%EC%A1%B0%EC%A0%81%20%EC%A7%88%EC%9D%98%20%EC%96%B8%EC%96%B4%28SQL%29%EC%99%80%20%EA%B3%A0%EA%B8%89%20%EC%BF%BC%EB%A6%AC%20%EC%B5%9C%EC%A0%81%ED%99%94%20-%20DDL%C2%B7DML%C2%B7DCL%2C%20%EC%84%9C%EB%B8%8C%EC%BF%BC%EB%A6%AC%2C%20%EC%A1%B0%EC%9D%B8%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%EA%B3%BC%20%EC%8B%A4%ED%96%89%20%EA%B3%84%ED%9A%8D.md) - 관계형 데이터베이스의 표준 언어 SQL(Structured Query Language)의 3대 서브셋(DDL: CREATE/ALTER/DROP, DML: SELECT/INSERT/UPDATE/DELETE, DCL: GRANT/REVOKE), 중첩 서브쿼리(단일행, 다중행 IN/ANY/ALL, 상관 서브쿼리 Correlated Subquery), 윈도우 함수(ROW_NUMBER, RANK), 조인 연산(Nested Loop Join vs Hash Join vs Sort-Merge Join), 인덱스 B+Tree 스캔 방식(Index Scan vs Index Range Scan vs Full Table Scan), 그리고 EXPLAIN 실행 계획 분석을 인터랙티브 SQL 조인 알고리즘 비용 비교기로 학습한다.
* [05. 데이터베이스 정규화 이론과 이상 현상 - 함수 종속성(FD), 1NF·2NF·3NF·BCNF 및 고급 정규형(4NF·5NF)](./05.%20%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B2%A0%EC%9D%B4%EC%8A%A4%20%EC%A0%95%EA%B7%9C%ED%99%94%20%EC%9D%B4%EB%A1%A0%EA%B3%BC%20%EC%9D%B4%EC%83%81%20%ED%98%84%EC%83%81%20-%20%ED%95%A8%EC%88%98%20%EC%A2%85%EC%86%8D%EC%84%B1%28FD%29%2C%201NF%C2%B72NF%C2%B73NF%C2%B7BCNF%20%EB%B0%8F%20%EA%B3%A0%EA%B8%89%20%EC%A0%95%EA%B7%9C%ED%98%95%284NF%C2%B75NF%29.md) - 릴레이션 중복으로 인한 3대 이상 현상(삽입 이상 Insertion, 삭제 이상 Deletion, 수정 이상 Update Anomaly), 함수 종속성(Functional Dependency: X -> Y)의 수학적 공리계(Armstrong's Axioms), 정규화 단계별 조건(1NF: 원자 도메인, 2NF: 부분 함수 종속 제거, 3NF: 이행적 함수 종속 제거, BCNF: 모든 결정자가 후보키), 다치 종속(MVD: X ->-> Y)을 해소하는 4NF, 조인 종속(JD)을 해소하는 5NF, 그리고 무손실 분해(Lossless Decomposition)와 종속성 보존을 인터랙티브 정규형 판별기로 학습한다.
* [06. 트랜잭션 격리성과 동시성 제어 - ACID 원칙, 2단계 로킹(2PL), MVCC 및 트랜잭션 격리 수준](./06.%20%E1%84%90%E1%85%B3%E1%84%85%E1%85%A2%E1%86%AB%E1%84%8C%E1%85%A2%E1%86%A8%E1%84%89%E1%85%A7%E1%86%AB%20%E1%84%80%E1%85%A7%E1%86%A8%E1%84%85%E1%85%B5%E1%84%89%E1%85%A5%E1%86%BC%E1%84%80%E1%85%AA%20%E1%84%83%E1%85%A9%E1%86%BC%E1%84%89%E1%85%B5%E1%84%89%E1%85%A5%E1%86%BC%20%E1%84%8C%E1%85%A6%E1%84%8B%E1%85%A5%20-%20ACID%20%E1%84%8B%E1%85%AF%E1%86%AB%E1%84%8E%E1%85%B5%E1%86%A8%2C%202%E1%84%83%E1%85%A1%E1%86%AB%E1%84%80%E1%85%A8%20%E1%84%85%E1%85%A9%E1%84%8F%E1%85%B5%E1%86%BC%282PL%29%2C%20MVCC%20%E1%84%86%E1%85%B5%E1%86%BE%20%E1%84%90%E1%85%B3%E1%84%85%E1%85%A2%E1%86%AB%E1%84%8C%E1%85%A2%E1%86%A8%E1%84%89%E1%85%A7%E1%86%AB%20%E1%84%80%E1%85%A7%E1%86%A8%E1%84%85%E1%85%B5%20%E1%84%89%E1%85%AE%E1%84%8C%E1%85%AE.md) - 데이터베이스 상태를 변화시키는 논리적 작업 단위 트랜잭션(Transaction)의 ACID 4대 특성(원자성 Atomicity, 일관성 Consistency, 격리성 Isolation, 지속성 Durability), 동시성 제어(Concurrency Control) 미수행 시 발생하는 4대 문제(갱신 분실 Lost Update, 오독 Dirty Read, 비반복 읽기 Non-repeatable Read, 유령 읽기 Phantom Read), 직렬 가능성(Serializability), 2단계 로킹 프로토콜(2PL: Growing/Shrinking Phase), 다중 버전 동시성 제어(MVCC - Undo Segment / Snapshot), 그리고 ANSI SQL 4대 격리 수준(Read Uncommitted, Read Committed, Repeatable Read, Serializable)을 인터랙티브 트랜잭션 격리 수준 시뮬레이터로 학습한다.
* [07. 데이터베이스 회복과 분산 NoSQL 아키텍처 - WAL 로그 회복(UNDO·REDO), Checkpoint, CAP 정리와 NoSQL 모델](./07.%20%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B2%A0%EC%9D%B4%EC%8A%A4%20%ED%9A%8C%EB%B3%B5%EA%B3%BC%20%EB%B6%84%EC%82%B0%20NoSQL%20%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98%20-%20WAL%20%EB%A1%9C%EA%B7%B8%20%ED%9A%8C%EB%B3%B5%28UNDO%C2%B7REDO%29%2C%20Checkpoint%2C%20CAP%20%EC%A0%95%EB%A6%AC%EC%99%80%20NoSQL%20%EB%AA%A8%EB%8D%B8.md) - 시스템 장애(트랜잭션 장애, 시스템 다운, 미디어 장애) 시 데이터 일관성을 복원하는 회복(Recovery) 메커니즘, Write-Ahead Logging(WAL) 원칙, 즉시 갱신(Immediate Update) vs 지연 갱신(Deferred Update)에서의 REDO와 UNDO 알고리즘, 체크포인트(Checkpoint)를 통한 복구 시간 단축, 분산 시스템의 CAP 정리(일관성 Consistency, 가용성 Availability, 분할 내성 Partition Tolerance), PACELC 정리, 그리고 4대 NoSQL 데이터 모델(Key-Value, Document, Columnar, Graph DB)을 인터랙티브 WAL 회복 및 CAP 정리 시뮬레이터로 학습한다.
