> [!abstract] 이 과목 자료의 성격
> 원본은 11편, 487쪽이다. 그런데 **한 파일 안에 두 계열의 슬라이드가 블록으로 번갈아 붙어 있다** — 로젠(Rosen) 8판을 옮긴 영어 슬라이드는 개념을 *의미*로 가르치고(자연어 번역, 시스템 명세, 예문), 한국어 교재 슬라이드는 `[표 2-1]`·`[정의 2-3]`·`[예제 2-14]` 같은 번호 붙은 도표로 *계산*을 가르친다(진리표, 연산자 우선순위표, 스택 파싱).
>
> 두 계열이 같은 개념을 다른 이름과 다른 기호로 부르는 자리가 여러 군데 있고, 같은 규칙을 두 번 적으면서 한쪽이 틀린 자리도 있다. 정리문서는 그 어긋남을 각 문서의 척추로 삼았다.
