## 원본에서 확인한 오류·불일치

### 논리 자료

- 52번 슬라이드 — Modus Tollens의 기호형이 `p → q`, **`¬p`** ∴ **`¬q`** 로 적혀 있다. 이는 전건 부정의 오류이고 반례가 있다(`p`=거짓, `q`=참). 같은 슬라이드 아래의 영어 예시("I will not study discrete math" ∴ "it is not snowing")는 정확하다
- 같은 슬라이드 — Corresponding Tautology가 `(¬q ∧ (p→q)) → ¬q` 로 적혔다. 결론은 `¬p`여야 한다
- 51번 슬라이드 — Modus Ponens의 Corresponding Tautology가 `(q ∧ (p→q)) → q`. 첫 항은 `p`여야 한다. 적힌 식도 항진식이기는 하지만 결론을 전제에 넣어 둔 형태라 규칙을 정당화하지 못한다
- 41쪽과 43쪽, 73쪽과 74쪽, 76쪽과 77쪽, 78쪽과 79쪽 — 각각 제목·본문이 같은 중복 슬라이드

### 집합 자료

- 10쪽 — 집합의 종류로 **"셀 수 없는 유한 집합(uncountable finite set)"** 을 든다. 유한 집합은 언제나 가산이므로 이 분류는 비어 있다. 12쪽 예제 3-5의 풀이가 "셀 수 없는 집합은 모두 무한집합이므로"라고 적어 스스로 반박한다
- 19쪽 — 진부분집합의 정의 문장("집합 A의 원소들 중에서 자기 자신을 제외한…")이 주어와 서술이 맞지 않아 정의가 되지 않는다. 11쪽 각주의 정의(`A ⊂ B` 이고 `A ≠ B`)가 맞다
- 43~46쪽 — 쪽 번호가 `43/42`부터 `46/42`까지 분모를 넘어간다. 그중 45쪽은 내용도 집합과 무관하다(시스템 프로그래머와 응용 프로그래머 비교)

### 관계 자료

- 표지는 "관계와 함수"인데 7쪽 목차 여섯 절에 함수가 없다. 함수 슬라이드는 목차 앞뒤(2·5·6·11~16·25쪽)에 흩어져 있다
- 11쪽과 25쪽 — 같은 슬라이드가 두 번 나온다
- 쪽 번호가 `n/112`인데 PDF는 125쪽이라 뒤쪽 열세 장이 분모를 넘어간다. 72·73쪽에는 `SKIP` 표시
- 74쪽 — 제목이 `Excercises`(→ Exercises)

### 그래프 자료

- 90번 슬라이드 — $K_{3,3}$(v=6, e=9)에 대해 `e > 3(v−2)`라 적었으나 $3(v-2) = 12$이므로 부등식을 **만족**한다. $K_{3,3}$은 이 필요조건을 통과하고도 비평면인 표준 반례이고, 바로 다음 91쪽이 면의 차수로 그 비평면성을 따로 증명한다
- 68·70번 슬라이드 — DFS·BFS 의사코드가 C 문법 안에 파이썬 콜론(`if( !VISITED[w] ):`)을 섞어 쓴다. 중괄호가 없어 `VISITED[w]=1;`이 조건 밖에 놓이고, 함수 끝의 중괄호 개수도 맞지 않는다
- 표지("5 트리와 그래프")·목차(7.x)·트리 슬라이드("8장 트리 학습")의 장 번호가 서로 다르다
- `Appendix 1` 6쪽 — Warshall 예제의 $W_4$ 행렬이 $W_3$가 아니라 $W_2$를 옮겨 적었다((1,4)와 (2,4)의 1이 빠졌다). 설명("더 이상 업데이트 하지 않음")은 정확하다. 단계 이름도 정의(STAGE0~3)와 예제(STAGE1~2)가 한 칸씩 밀려 있다
- `Appendix 2` 3쪽 — Welch-Powell의 정점 나열이 `c, a, d, e, b, f`인데 차수는 5, 3, 3, **2**, **3**, 2다. 알고리즘 2)단계의 "차수 내림차순"을 어긴다. 같은 슬라이드의 색 배정도 4)단계("인접하지 않은 정점을 모두 같은 색으로")를 따르지 않아 `b`와 `f`가 색을 받지 못한다
- `Appendix 2` 2쪽 — 예시 코드 `'b' : [ 'c', 'f'` 에 닫는 대괄호가 없다
- `Appendix 2` 6·7쪽 — "Optimize some codes" 두 장의 코드가 앞 슬라이드와 한 글자도 다르지 않다. 주석만 붙어 있다

### 트리 자료

- 56번 슬라이드 — "중위 표기법(infix) • **전위** 탐방하여 찾은 자료들을 선형으로 나열". 중위 탐방이어야 한다(65번 슬라이드는 정확하다)
- 15번 슬라이드 — "n = 2일 때 2진 트리 혹은 완전 2진 트리라고 한다". 앞의 두 줄이 "기껏해야 n개"와 "정확히 n개"로 구분한 두 개념을 다시 합쳐 버린다
- 9번 슬라이드 — "there is a unique simple path **but** between any pair of its vertices"에 `but`이 잘못 끼어 있다
- 23번 슬라이드 — `CALL PRINT ('ANSWER IS TOO LAGER')` (→ LARGER)
- 43번 슬라이드 — "나의 원룸 입지 구하기" 그래프에 **물음이 적혀 있지 않다.** 다음 슬라이드는 곧바로 다음 절 표지로 넘어간다
